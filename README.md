🎵 ECHOVE — Terminal Lyrics Sync Player

ECHOVE is a mini Python-based karaoke lyric sync tool that displays original song lyrics and English translations in real-time — perfectly synced with the music playing locally.
Built for music lovers who want to feel the song and understand it. 🎧✨

✨ Features

🎤 Real-time lyric sync with audio

🌍 Dual-language support (Original + English translation)

🎨 Colored terminal lyrics for immersive experience

⏱️ Timing engine to match music beats

🧵 Thread-based audio playback

💬 Smooth word-split lyric animation

🖥️ Works right in the terminal — lightweight & fun

🧠 Tech Stack

Python

pygame (audio playback)

colorama (terminal text colors)

threading, time (sync logic)

🚀 Future Improvements

GUI version (Tkinter / PyQt / Web app)

Auto-translate lyrics using APIs

Beat detection / auto-timing system

Karaoke-style highlight (word-by-word)
